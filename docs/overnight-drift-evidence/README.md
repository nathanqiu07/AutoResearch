# Overnight agent drift: demo evidence

Start with the [teammate summary](summary.md). The [full brief](index.html) includes user intent, four failure exhibits, a timeline, causal interpretation, limits, a 60–75 second demo script, and embedded source receipts. Download the HTML and open it locally to view the report; GitHub displays its source.

## Evidence

- [Readable evidence ledger](evidence.md): 30 selected receipts from 18 original source files.
- [Structured evidence](evidence.json): the same excerpts with source identifiers, original line numbers, timestamps where available, and source hashes.
- [Publication checks](publication.json): scope and verification limits.

This is the original November 14–15 overnight campaign and its morning review, not the later recovery campaign. Broad exploration was authorized. The case concerns weak experimental judgment and incomplete integration, not the mere existence of negative results or an allegation of fabricated success.

## Publication scope

Prepared at Gio's request for the hackathon demo. This package contains selected task-relevant quotations and artifact excerpts, not full chat logs, credentials, or unrelated account data. Machine-specific filesystem paths were replaced with portable identifiers; clarification-tool metadata was omitted. Underlying originals remain local. SHA-256 values identify those originals; they are not hashes of the shortened excerpts. Source identifiers alone do not give readers access to private files.

No experiment code, datasets, or teammate-owned results were changed. No experiments were rerun. HTML content and internal anchors were checked statically; visual rendering was not verified because the local-file browser preview was blocked. The summary and evidence ledger can be read directly on GitHub.
