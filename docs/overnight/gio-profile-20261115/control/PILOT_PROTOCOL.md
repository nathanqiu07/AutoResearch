# Development pilot protocol

Frozen before the first candidate call. Goal: verify that released sources, profile construction, controlled personalization and private scoring run end to end with valid outputs and measurable usage. Expected: every supported control constructs the declared payload; P1 yields a nonempty structurally supported summary where the cap permits; predictions have valid distributions. A malformed/empty/oversized profile, source or schedule mismatch, missing usage, or unverifiable settings counts against readiness and remains visible. This pilot does not select a winning method.

Use active development-v2 only, after checking its exact receipt and bundle hashes. It has 14 semantic contextual judgments, 28 ordered inputs, and 3 independent source groups; two option orders are repeated measures, not separate judgments. Fit bundles are unchanged from v1. Confirmation is unavailable and unauthorized. Source-known archival labels are not scientific ground truth or an independent general-capability measure.

First batch: gpt-6-luna via Responses API, reasoning medium, tools absent, store false, standard tier, common consumer prompt and explicit output allowance. Start with no-profile/name-only/raw/lexical controls plus P1 at cap 2048 conservative UTF-8 bytes, explicit-only, extraction replicate 0, both researchers. Use the first two semantic item pairs by the frozen item order for throughput/validity checks; exact ordered IDs are fixed in immutable job manifests before execution. Maximum 100 attempts, two concurrent requests, $0.50 incremental API suballocation, per-call timeout 60 seconds, deadline 2026-11-15T17:00:00Z. No retry of uncertain calls. Constructor-only control builds may make 0 model calls and must report that.

All calls are dispatched as explicit immutable manifests/leases through the pinned runner and one canonical shared SQLite ledger. The ledger's maximum 9.999994875 USD accounts for the prior 0.000005125 USD API access probe outside it. No API key enters a packet, trace or Git. New code gets a new immutable runtime snapshot.

After the pilot, expand the matched v2 panel and profile grid only if source/settings/usage checks hold. Full core grid remains 8 families ×3 caps ×2 evidence policies ×3 extraction replicates ×2 researchers when feasible. First screen one replicate, then promote one within-family configuration plus two global slots and score across three replicates. Report invalid/unavailable cells and failures. Preserve the $4 scaling reserve and 05:00–07:30 Pacific scaling window. Any later evidence version creates new manifests; never rewrite an executed row.

If no-profile/name-only controls already saturate these contextual labels, flag a ceiling rather than call profile generation an improvement. Additional independent source evidence and utility handoff then take priority over adapting repeatedly to the same few judgments. Scaling remains a descriptive matched comparison; no parameter-count or scaling-law claim.
