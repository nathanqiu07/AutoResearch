# Reviewed control-source snapshot

This preserves the exact 20 code and test files approved by audit052 for source retention. The 156,748 payload bytes match the original hashes in `SOURCE_MANIFEST.json`. The source proposal, publication decision and copy receipt record the exact scope.

These are historical control sources, not a portable release or new execution authority. Absolute paths, dependency pins and self-file checks remain unchanged. Their private inputs, caches, ledgers, credentials, issued authorities, diagnostic bodies and denylist JSON are excluded. Referenced files were not followed during copying.

Sources were parsed as Python and hashed without import or execution. Publication eligibility is separate from behavior, execution, scientific validity and scoring. Existing owner/reviewer receipts retain those narrower claims. Never run these historical launchers as a new campaign or use old authorization files to retry requests.
