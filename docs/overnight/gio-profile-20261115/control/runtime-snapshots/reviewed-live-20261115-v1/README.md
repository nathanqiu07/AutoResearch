# Reviewed runtime source snapshots

These are exact copies of the code used for the November 15 continuation: the request diagnostics, external execution wrapper, finite profile queue, and reference queue. The source proposal records original paths, hashes, review receipts, and the purpose of each file. The retention receipt records the copy check.

These files preserve provenance. They are not portable launchers: their absolute paths and input hashes refer to this campaign. Copying them here does not change the running code or authorize another run. In particular, do not import the offline request reconstruction helper into a live process; it deliberately disables network access.

The snapshot includes synthetic offline tests and review metadata. Private prompts, source text, labels, model responses, credentials, caches, and live databases are excluded. Review receipts refer to separately retained private evidence. Passing these tests establishes the checks they cover, not scientific validity or a model benefit.
