## Presentation checks

- Match the source author, profile researcher, run ID and condition across the page.
- Use the actual run's version of the scenario, tools, models and settings. Do not mix a revised packet with an older run.
- Keep “partial snapshot” visible while work is incomplete. Save a new immutable render when a newer index arrives.
- If the provider or live browser fails during the demo, use the latest verified local **recorded** snapshot and name its time. The fixture is only an interface fallback, with its fixture banner visible.
- Do not select a favorable arm, hide failures, or imply measured benefit from a staged correction. The evaluator's result determines the claim.
