 I'm quite excited about the theory part. When defining interpretability approaches from empirical intuitions, it is hard to argue why one approach should be better. Thus, it would be nice if we could derive our methods or at least link them to some high-level principle.

 We attempt to link explanations and features to the loss landscape. Simplified, "good" features are those that explain why the model has low training loss and that explain the generalization behavior of the model as described/measured by degeneracy in the loss landscape.

 In the theory paper, we then identify 3 concrete ways in which neural networks can be degenerate: linear dependence between activations, linear dependence between gradients, and synced ReLUs. We also make a heuristic argument that modular networks are more likely to be degenerate

 While this is very early days, I feel like "degeneracy in the loss landscape" might eventually work as a guiding principle for interpretability tools, e.g. explain why some tools work and others don't or enable the development of new methods.

 Of course, it might also turn out to be the wrong principle. In any case, I think if we eventually want to make statements like "We explained the important parts of the network," we will need a theory to guide us, e.g. to tell us what is "important" and what "explained" means.

 Following this theory, we then suggest a new interpretability technique. Unfortunately, the theory is not complete, so we need to make additional assumptions for the method that don't directly follow from the theory. The method is called Local Interaction Basis (LIB). 

 In short, it's like a fancy PCA that orthogonalizes activations and interactions at the same time. 

Simplified, the goal is to create a graph that is as sparsely activated as possible (minimal number of interactions) while maintaining maximal model performance. 

 Our results are worse than we hoped. While we find sparse and interpretable graphs for small toy models (modular addition transformer, CIFAR10 MLP), small LMs (Tinystories, GPT2-small) are neither very sparse nor more human-interpretable than a simple PCA baseline.

 We interpret this as a negative result for LIB and think that one of the additional assumptions we made was false. 

Nevertheless, I think the theory is useful, and I'm excited about work that develops new methods using degeneracies in the loss landscape as a guiding principle.
