- Prefers building or using simple code tools for black-box investigation over working only in the bare playground, because fiddly prompt-engineering work benefits from programmatic support.
- Prefers deep hands-on interactive familiarity with model behavior over purely internals-based or abstract analysis, because good hypotheses about what to test and what to explain come from long interaction.
- Prefers distrusting bad behavior found through hard adversarial search as evidence of scheming, because models are not adversarially robust and non-schemers also produce bad or incoherent outputs.
- Prefers reasoning about synthetic-input detection in Bayesian terms, because a given tell matters less as the prior that inputs are synthetic rises at scale.
- Prefers calibrated, prior-aware interpretation of evidence over treating single observations as decisive, because one observation only shifts beliefs much if egregious misalignment was already plausible.
