Audit 045 provides a compact navigation index of the integration audit's useful
findings and limits. The maintained document is
[What the integration audit found and changed](../../../docs/user-models/integration-audit/FINDINGS.md).

The original draft, editorial notes and exact 19 public source pins are retained
here. All source bytes, sizes and line counts were checked against Git commit
`32513a519ee5b544608e43a0348669bfd235e3de`. The root-derived document uses portable
links, clarifies the serialized-byte limits and distinguishes the two separate
672-row scopes. Its exact hash and those changes are in `root-verification.json`.

This is a synthesis of previously recorded findings, not a new empirical result
or a fresh retest of every repair. It distinguishes historical defects, scoped
independent retests, owner-reported later fixes, missing evidence and unresolved
policy choices. Audit 044's subsequent private retention is outside its source
cut; the evolving overview links that later work separately.

The full source bodies are existing committed public Git objects; this package
does not duplicate them or claim to be a standalone archive. Final package hashes
are in `checksums.json`. No raw profile, private score, model call, owner edit or
model/settings change was needed to create this index.
