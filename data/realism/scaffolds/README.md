# Open-source agent scaffold prompts

These are the system prompts and tool schemas of open-source coding and ops agents, copied verbatim and retrieved 2026-11-15. They ground realistic Petri audit seeds. All of the text is published by each project under its own open license; no leaked or proprietary prompts are included.

Each `<name>.json` has `name`, `source_url` (a permalink pinned to a commit), `commit`, `license`, `retrieved`, `system_prompt` or `system_prompts` (`{variant: text}`), and `tools`. Most files also have `notes`, which say how the tools were transcribed and which runtime choices were made. Template placeholders (`{{...}}`, `{% %}`, `{fence[0]}`, `${...}`) are kept as written.
